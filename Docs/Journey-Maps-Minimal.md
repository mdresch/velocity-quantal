This document contains concise journey maps and minimal wireframe outlines for four priority roles.

1) Entrepreneur — High-level journey
- Stages: Discover → Pick → Start Pilot → Execute → Validate → Scale
- Touchpoints: Opportunity list, Opportunity detail, Start Pilot modal, Pilot dashboard, Evidence upload, Mentor feedback
- Success metrics: pilot started, evidence uploaded, mentor sign-off, initial revenue/KPIs
- Minimal screens / wireframe outline:
  - Opportunity List (filters, tags, bookmark)
  - Opportunity Detail (template link, effort, start button)
  - Start Pilot (form: pilot name, timeline, team, budget)
  - Pilot Dashboard (milestones, evidence list, upload control)

2) Mentor / Advisor — High-level journey
- Stages: Discover → Review → Advise → Sign-off
- Touchpoints: Mentor dashboard, Opportunity/Pilot review pages, Annotation panel, Milestone review
- Success metrics: annotated items, sign-offs, mentor hours logged
- Minimal screens / wireframe outline:
  - Mentor Dashboard (assigned pilots, pending reviews)
  - Pilot Review (evidence timeline, accept/reject milestone)
  - Annotation UI (inline comments, ratings)

3) Project Manager (PM) — High-level journey
- Stages: Plan → Assign → Monitor → Escalate → Report
- Touchpoints: Cohort dashboard, Pilot detail, Assignment modal, Alerts/notifications
- Success metrics: pilot health index, mentor engagement, time-to-decision
- Minimal screens / wireframe outline:
  - Cohort Dashboard (pilot health, filters)
  - Pilot Assignment (assign owner, mentors, timeline)
  - Issue / Escalation Panel

4) Admin — High-level journey
- Stages: Onboard → Configure → Manage → Audit
- Touchpoints: User management, Role management, Template library, Audit logs
- Success metrics: users onboarded, role changes, template publishing time
- Minimal screens / wireframe outline:
  - User Invite & Roles (invite form, role assign)
  - Role Management (role permissions matrix)
  - Template Library (CRUD, publish)
  - Audit Logs (activity timeline, exports)
